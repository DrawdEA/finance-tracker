# finance-tracker

Chat-first personal finance tracker: log transactions by talking to Claude (mobile + desktop) via a remote MCP server, with catch-up estimates for gaps in tracking.

## Agent skills

### Issue tracker

Issues live in GitHub Issues for DrawdEA/finance-tracker, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
